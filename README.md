# 🐉 NOVA-DRAGON — مستودع المشروع الواحد

> **المهمة العليا (الدستور §1):** بوت تداول محافظ هو مصدر الدخل المستقبلي وصندوق الزواج. ومعيار الحكم واحد: **التوقع الرياضي بعد التكلفة** — لا نسبة فوز عالية، ولا وعد باحتمال ربح.

## 🚪 بروتوكول الاستئناف (أي جلسة جديدة — بهذا الترتيب حرفيًا، الدستور §8.4)

1. `CONSTITUTION.md` — **الدستور الحاكم، 20 قسمًا بالإنجليزية.** يُقرأ كاملًا قبل أي أمر، ويُبطل كل دستور قبله.
2. `docs/HANDOFF.md` — وثيقة التسليم الحية: أين نحن الآن وما التالي.
3. `docs/DECISIONS.md` و`docs/CONSTITUTION-AMENDMENTS.md` — القرارات الملزمة وسجل التعديلات.
4. `docs/journal/` — الشريط: آخر نبضة قبل أول حركة.
5. **ملف القيود المرقّم** — قيود الجولة القادمة، كل قيد ملزم ومرقّم.
6. آخر كتلتين من `LOG.md` — ماذا حدث مؤخرًا.
7. `INDEX.md` — خريطة كل ملف (تُعاد ولادتها بأمر `python3 tools/build_index.py`).
8. `BACKLOG.md` — قائمة المؤجلات وأفكار الاختراع.
9. آخر فرع نتائج في `history/research/hyp_lab_out/`.
