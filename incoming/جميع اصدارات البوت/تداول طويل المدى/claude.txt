# خطة شاملة لموازنة البوت وتحسين أدائه

## 1️⃣ **تشخيص المشكلة الأساسية**

مشكلتك الحالية هي **المعضلة الكلاسيكية للتداول الخوارزمي**:
- **تشديد الشروط** → إشارات نادرة جداً (Precision عالية، Recall منخفض)
- **تخفيف الشروط** → إشارات كثيرة فاشلة (Recall عالي، Precision منخفض)

## 2️⃣ **الحلول الاستراتيجية**

### **أ) نظام التصفية المرحلي (Multi-Stage Filtering)**

بدلاً من شروط صارمة أو مخففة، استخدم **نظام تسجيل نقاط**:

```python
def calculate_signal_score(symbol_data):
    score = 0
    
    # المرشحات الإلزامية (50 نقطة)
    if price > ema200_15m:
        score += 50
    else:
        return 0  # رفض فوري
    
    # MSS Quality (0-20)
    mss_strength = (break_high - structure_high) / atr_5m
    if mss_strength > 0.8:
        score += 20
    elif mss_strength > 0.5:
        score += 12
    elif mss_strength > 0.3:
        score += 5
    
    # FVG Quality (0-15)
    fvg_gap = (candle[i-1].low - candle[i+1].high) / atr_5m
    if fvg_gap > 0.4:
        score += 15
    elif fvg_gap > 0.25:
        score += 8
    
    # Order Book Imbalance (0-15)
    imbalance_ratio = bid_volume / ask_volume
    if imbalance_ratio > 2.5:
        score += 15
    elif imbalance_ratio > 1.8:
        score += 10
    elif imbalance_ratio > 1.3:
        score += 5
    
    return score

# التنفيذ فقط إذا Score >= 70
```

```python
# رفض الإشارات خلال حجم تداول منخفض
```

```python
# تأكد من قوة الاتجاه
ema50_5m = calculate_ema(closes, 50)
```

```python
# رفض الدخول إذا كان السعر بعيداً جداً عن EMA
```

## 3️⃣ **تحسين إدارة المخاطر**

### **أ) حجم الصفقة الديناميكي**
```python
def calculate_position_size(win_rate, consecutive_losses):
    base_size = 20  # USDT
    
    # قلل الحجم بعد خسائر متتالية
    if consecutive_losses >= 3:
        return base_size * 0.5
    elif consecutive_losses >= 2:
        return base_size * 0.75
    
    # زد الحجم مع نسبة نجاح عالية
    if win_rate > 0.65:
        return base_size * 1.5
    
    return base_size
```

## 4️⃣ **نظام التعلم والمعايرة**

### **أ) تتبع الأداء لكل فلتر**
```python
class FilterPerformanceTracker:
    def __init__(self):
        self.filter_stats = {
            'mss_strong': {'trades': 0, 'wins': 0},
            'fvg_wide': {'trades': 0, 'wins': 0},
            'imbalance_high': {'trades': 0, 'wins': 0}
        }
    
    def record_trade(self, filters_passed, win):
        for filter_name in filters_passed:
            self.filter_stats[filter_name]['trades'] += 1
            if win:
                self.filter_stats[filter_name]['wins'] += 1
    
    def get_best_filters(self):
        # ابحث عن المرشحات ذات أعلى نسبة نجاح
        return sorted(
            self.filter_stats.items(),
            key=lambda x: x[1]['wins'] / max(x[1]['trades'], 1),
            reverse=True
        )
```

## 5️⃣ **خطة التنفيذ العملية**

### **المرحلة 1: جمع البيانات (أسبوع واحد)**
1. شغل البوت في **وضع التسجيل فقط** (لا تداول)
2. سجل كل إشارة محتملة مع:
   - قيم جميع المؤشرات
   - ماذا كان سيحدث لو نفذت الصفقة
3. احفظ البيانات في ملف CSV

### **المرحلة 2: التحليل**
```python
import pandas as pd

df = pd.read_csv('signals_log.csv')

# احسب نسبة النجاح لكل مستوى Score
for score_threshold in range(60, 90, 5):
    subset = df[df['score'] >= score_threshold]
    win_rate = subset['would_win'].mean()
    frequency = len(subset) / 7  # عدد الإشارات يومياً
    
    print(f"Score >= {score_threshold}: Win Rate = {win_rate:.2%}, Signals/day = {frequency:.1f}")
```

### **المرحلة 3: المعايرة**
- اختر `score_threshold` الذي يحقق:
  - نسبة نجاح ≥ 55%
  - 3-8 إشارات يومياً
  
- اضبط أوزان المرشحات بناءً على البيانات

### **المرحلة 4: الاختبار الحي**
- شغل البوت بالإعدادات الجديدة
- راقب لمدة أسبوع
- عدل تدريجياً
