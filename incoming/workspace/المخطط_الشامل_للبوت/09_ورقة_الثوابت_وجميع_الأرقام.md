## 5) قواعد الدخول والخروج

| القاعدة | القيمة |
|---------|--------|
| **الدخول** | `buy_votes >= 4` **و** `sell_votes == 0` (من 7 مؤشرات) |
| **الخروج / عدم الدخول** | `sell_votes >= 3` |
| غير ذلك | `HOLD` (تأجيل) |
| عدد المؤشرات المصوّتة | **7** (RSI, MACD, BOLL, EMA, ADX, STOCH, OBV) |

### الوقف والهدف (البوت الأساسي)
```
Stop_Loss   = Entry_Price − (2.0 × ATR)
Take_Profit = Entry_Price + (3.5 × ATR)
```

### الوقف الديناميكي بالـ ATR
| حالة السوق | `k` في `Entry − k × ATR` |
|-----------|--------------------------|
| مستقرة | **1.5 – 2.0** |
| شديدة التقلّب | **2.5 – 3.0** |

### الوقف الهيكلي
```
أدنى قاع لآخر 10 – 20 شمعة − (0.2 × ATR)
```

### Chandelier / ATR Trailing
```
انعكاس بمقدار 1.5 × ATR ⇒ خروج
```

## 6) محرك الخروج الهجين (النسخة الاحترافية)

| العنصر | القيمة |
|--------|--------|
| نوع أمر الدخول | **`LIMIT_MAKER` (Post-Only)** عند أفضل Bid من `@bookTicker` |
| منع أوامر السوق للدخول | ✅ ممنوع قطعياً |
| مهلة الرصاصة المعلّقة | **12 ثانية** |
| **Micro-Tick Cancel** | انخفاض **2 ticks** أو **> 0.05%** خلال **2.5 ثانية** ⇒ إلغاء فوري |
| الوقف الصلب على المنصة | `STOP_LOSS_LIMIT` بمسافة **`1.15 × ATR(1m)`** |
| تثبيت الوقف الصلب | **أدنى حد 0.30%** · **أقصى حد 3.0%** |
| قفل التعادل | عند ربح **`+0.50%`** ⇒ قفل الوقف عند **`+0.45%`** |
| تفعيل التتبّع | عند **`+1.5 × ATR`** (أو `+0.50%`) |
| مسافة التتبّع — المرحلة 1 | **`1.2 × ATR`** (ربح بين `0.50%` و `1.0%`) |
| مسافة التتبّع — المرحلة 2 | **`0.5 × ATR`** (أو `0.08%`) فور تجاوز الربح **`1.0%`** |
| تنفيذ الخروج المربح | إلغاء الوقف الصلب + **`MARKET SELL`** |
| الوقف الزمني المايكروي | مفتوح **> 60 ثانية** وربح **< 0.10%** ⇒ `MARKET SELL` طارئ |
| حارس الجدار المعاكس | `ask_qty > 3.0 × bid_qty` ⇒ **VETO (HOLD)** |

## 10) التقنيات المتقدمة — الأرقام فقط

| التقنية | الرقم/العتبة |
|---------|--------------|
| **Lead-Lag** | معامل ارتباط **> 0.85** · نافذة تأخّر **τ** من ثوانٍ إلى دقائق |
| **Hurst (H)** | `≈ 0.5` ⇒ تجميد · `> 0.55` ⇒ زخم · `< 0.45` ⇒ ارتداد |
| **ضجيج السوق** | **> 70%** من حركة الكريبتو ضجيج عشوائي |
| **Cointegration** | اختبار **ADF** · انفصال **Z-Score > ±2** |
| **Cross-Sectional** | أفضل **50** زوج · **Top Decile** |
| **Fractional Differentiation** | الدرجة **d = 0.4** |
| **Dynamic PCA** | أفضل **20 – 50** عملة بديلة مقابل BTC |
| **Adverse Selection** | قياس عند **t+10s · t+30s · t+60s** |
| **CVaR** | تجميد الدخول عند تجاوز حد آمن |
| **Infinity Grid** | شراء **20$** ⇒ تقييم **24$** ⇒ بيع الفائض **4$** وإبقاء **20$** |
| **تباعد DCA** | **1.5% → 3% → 5%** |
| **الإحماء (Warm-up)** | آخر **1000 صفقة + 500 شمعة** عبر REST |
| **التحكم بالتزامن أثناء الإحماء** | **`asyncio.Semaphore(3)`** |
| **Stoikov Micro-Price** | `P_micro = P_bid×(Q_ask/(Q_bid+Q_ask)) + P_ask×(Q_bid/(Q_bid+Q_ask))` |

## 12) قائمة محاذير (Do / Don't)

| ✅ افعل | ❌ لا تفعل |
|---------|-----------|
| استخدم **WebSockets** للبيانات الحية | استدعاءات **REST** متكررة |
| **Vectorized** (numpy/pandas) | حلقات على كل شمعة |
| **`LIMIT_MAKER`** للدخول | **Market orders** للدخول |
| **وقف مرتبط بـ ATR** | نسبة مئوية ثابتة |
| **مجموعات صغيرة متجانسة** من المؤشرات | حشر **50 مؤشراً** (تضارب خطي) |
| **حفظ السجل في ملفات/SQLite** | طباعته على شاشة Termux |
| صلاحية **قراءة + تداول فوري** فقط | تفعيل صلاحية **السحب** |
| **Walk-Forward** قبل الاعتماد | تطبيق الخلاصة مباشرة (Overfitting) |
| **Chunking / memory_map** | تحميل 31.5 مليون صف في RAM |
| **نسخة احتياطية خارجية** قبل الحذف | ترك النسخ القديمة في المصادر |
