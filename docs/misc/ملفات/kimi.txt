المشكلة التي تواجهك هي **مشكلة التوازن بين الدقة والتردد (Precision vs. Frequency)**، وهي أزمة كلاسيكية في أنظمة السكالبينج. بناءً على وصف البوت، إليك التشخيص الجذري والحلول العملية:

### أولاً: تشخيص لماذا تفشل الصفقات عند تخفيف الشروط

عندما تُرخي شروط الدخول، يدخل البوت في **"فخ السيولة الكاذبة"**:
1. **FVGs ضعيفة**: في سبوت بينانس، 80% من فجوات FVG على 5 دقائق تُملأ خلال 60 ثانية (فترة انتظارك الحالية)، مما يجعلك تدخل قمم/قيعان مؤقتة.
2. **BookTicker Spoofing**: الماركت ماكرز في سبوت يضعون أوامر وهمية ضخمة ثم يسحبونها خلال مللي ثانية. الـ Imbalance اللحظي غير موثوق.
3. **EMA200 كفلتر وحيد**: في الأسواق العرضية (Sideways)، السعر يعبر EMA200 باستمرار مما يولد إشارات خاطئة.

### ثانياً: الحلول الفورية (Quick Fixes)

#### 1. تعديل نظام "الطلقة المعلقة" (Hanging Bullet)
**المشكلة**: 60 ثانية فترة طويلة جداً في السكالبينج.
```python

```

#### 2. فلتر السيولة الديناميكي (Liquidity Filter)
أضف هذا الشرط قبل الدخول:
- **حجم الدفتر (Depth)**: يجب أن يكون حجم طلبات الشراء في أول 5 مستويات (Level 5) أكثر من 3x حجم صفقتك ($20).
- **الانتشار (Spread)**: لا تدخل إذا كان الفرق بين الأعلى سعر شراء وأقل سعر بيع > 0.05%.

#### 3. تأكيد الزخم (Momentum Confirmation)
بدلاً من الاعتماد على MSS + FVG فقط، أضف:
```python
# مؤشر القوة النسبية على دقيقة واحدة
rsi_1m = calculate_rsi(period=14, timeframe="1m")
# فقط إذا كان RSI بين 45-65 (منطقة الزخم الصحيح، ليست اشباع)
if 45 < rsi_1m < 65 and rsi_1m > rsi_1m_previous:
    allow_entry()
```

### ثالثاً: نظام الـ Adaptive ATR (التحكم الذكي في وقف الخسارة)

هذا هو المطلوب لجعل SL يتنفس مع السوق:

```python
def calculate_adaptive_sl_tp(candles_5m, candles_1h):
    # ATR الحالي على 5 دقائق
    atr_5m = talib.ATR(candles_5m['high'], candles_5m['low'], candles_5m['close'], timeperiod=14)[-1]
    
    # ATR المرجعي على ساعة (لمعرفة إذا كان التذبذب الحالي استثنائياً)
    atr_1h = talib.ATR(candles_1h['high'], candles_1h['low'], candles_1h['close'], timeperiod=14)[-1]
    atr_1h_mean = atr_1h.mean()  # متوسط 20 فترة سابقة
    
    # نسبة التقلب الحالية
    volatility_ratio = atr_5m / atr_1h_mean
    
    # تحديد المضاعفات
    if volatility_ratio > 1.8:  # سوق متفجر
        sl_multiplier = 3.0
        tp_multiplier = 6.0  # نحافظ على 1:2
        # إضافة: استخدام Trailing Stop هنا فقط
    elif volatility_ratio < 0.6:  # سوق نائم
        sl_multiplier = 1.2
        tp_multiplier = 2.4
    else:  # طبيعي
        sl_multiplier = 2.0
        tp_multiplier = 4.0
    
    # تعديل إضافي بناءً على "سرعة" الشمعة الحالية
    current_range = candles_5m['high'][-1] - candles_5m['low'][-1]
    if current_range > (2.5 * atr_5m):  # شمعة نارية
        sl_multiplier *= 1.3  # نوسع قليلاً لتجنب الـ Wick
    
    sl = entry_price - (sl_multiplier * atr_5m)
    tp = entry_price + (tp_multiplier * atr_5m)
    
    return sl, tp, sl_multiplier  # نعيد المضاعف لنعرف إذا كان علينا استخدام Trailing
```

**الفكرة**: في التذبذب العالي، لا توسع SL فقط، بل **استخدم Trailing Stop** بدلاً من SL ثابت:
- إذا تحرك السعر لصالحك بمقدار 1.5x ATR، انقل SL إلى نقطة الدخول (Breakeven).
- إذا وصل الربح إلى 3x ATR، فعّل Trailing بمسافة 2x ATR.

### رابعاً: لماذا يخسر البوت أكثر من تداولك اليدوي؟ (الفرق الجوهري)

أنت عندما تتداول يدوياً، تقوم بأشياء لا يفعلها البوت:
1. **القراءة السياقية (Context)**: ترى أن السعر عند دعم قوي على 4 ساعات، فتتجاهل إشارة بيع صغيرة. البوت يأخذ الإشارة بلا سياق.
2. **تقدير الـ Wick**: ترى أن الـ Wick طويل والشراء فيه خطر، البوت يرى "MSS" فقط.
3. **التحكم النفسي**: أنت لا تدخل إذا شعرت أن السوق "كاذب" (Fakeout)، البوت يدخل.

**الحل البرمجي**: إضافة **فلاتر السياق (Context Filters)**:
```python
# 1. فلتر الدعم/المقاومة (الأهم)
pivot_high = talib.MAX(candles_1h['high'], timeperiod=20)[-1]
pivot_low = talib.MIN(candles_1h['low'], timeperiod=20)[-1]
distance_to_resistance = (pivot_high - current_price) / current_price

if distance_to_resistance < 0.005:  # أقل من 0.5% عن مقاومة قوية
    reject_buy_signal = True  # لا تشتري عند السقف

# 2. فلتر الوقت (Time Filter)
current_minute = datetime.now().minute
if current_minute % 5 >= 4:  # آخر دقيقة من الشمعة الخمسية
    skip_entry = True  # تجنب الدخول قبل إغلاق الشمعة (تجنب Fakeout)

# 3. فلتر الحجم النسبي (Volume Confirmation)
volume_sma = candles_5m['volume'].rolling(20).mean()[-1]
if current_volume < volume_sma * 1.5:
    skip_entry = True  # لا يوجد اهتمام حقيقي من السوق
```
