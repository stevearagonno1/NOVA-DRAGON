## 3. التكلفة — كل الأرقام مقفلة

### 3.1 المنصة المرجعية

```text
Binance USDT-M Perpetual Futures
شريحة VIP 0
بلا خصم BNB  ← الافتراض المحافظ الملزم
```

### 3.2 جدول الرسوم المقفل

| البند | القيمة |
|---|---:|
| maker USDT-M VIP0 | 0.0200% |
| taker USDT-M VIP0 | 0.0500% |
| taker مع خصم BNB 10% | 0.0450% |
| maker USDC-M VIP0 | 0.0000% |
| taker USDC-M VIP0 | 0.0400% |

المصادر التي يجب ذكرها في التقرير:

```text
bitsgap.com/blog/binance-trading-fees-explained-what-it-costs
cryptopotato.com/binance-fees
```

### 3.3 السيناريوهات الأربعة الإلزامية

احسب الأربعة كلها. السيناريو رقم 1 هو **وحده** الملزم للحكم.

```text
S1  taker/taker USDT-M بلا خصم    رسوم ذهاب وإياب = 0.1000%   ← ملزم
S2  maker/taker USDT-M بلا خصم    رسوم ذهاب وإياب = 0.0700%   ← استرشادي
S3  taker/taker USDT-M بخصم BNB   رسوم ذهاب وإياب = 0.0900%   ← استرشادي
S4  maker/taker USDC-M            رسوم ذهاب وإياب = 0.0400%   ← استرشادي
```

### 3.4 حجم الصفقة المقفل

```text
notional = 10,000 USDT لكل صفقة
```

لا تسأل عن غيره. إن أردت حساسية، أضف 1,000 و100,000 كأعمدة استرشادية فقط.

### 3.5 تقدير السبريد — لا توجد بيانات دفتر أوامر

بياناتنا OHLCV فقط، فالسبريد يُقدَّر لا يُقاس. المقدّر المقفل:

```text
Corwin–Schultz high–low spread estimator على شموع الدقيقة
نافذة التجميع: شهرية، ثم متوسط مرجح بالحجم
القيم السالبة تُقصّ إلى صفر
```

إن فشل المقدّر على أصل ما، استخدم البديل المقفل:

```text
Roll estimator على عوائد الدقيقة
وإن فشل أيضًا، افترض سبريد = 0.0200% وسجّل ذلك صراحة
```

### 3.6 الانزلاق — مقفل

```text
slippage_taker = 0.5 × spread + 0.0100%
slippage_maker = 0
```

الجزء الثابت `0.0100%` هو تقدير أثر السوق عند 10,000 USDT على عقد دائم سائل. مُعلن كافتراض، لا يُناقش.

### 3.7 المعادلة النهائية

```text
cost_pct_S1 = 0.1000% + spread + 2 × slippage_taker
cost_R      = cost_pct / ATR_pct
```

حيث `ATR_pct` هو متوسط ATR(14) على 4H مقسومًا على السعر، محسوبًا على فترة holdout لكل أصل على حدة.

### 3.8 حدود القرار — احفظها

```text
0.0287R  = الحد المحافظ  (Wilson lower = 0.5144)
0.0766R  = الحد النقطي   (win_rate = 0.5383)
```

### 3.9 جدول الحسم — أقل ATR% مطلوب

| تكلفة إجمالية | لتمرير الحد المحافظ | لتمرير الحد النقطي |
|---:|---:|---:|
| 0.040% | ATR ≥ 1.39% | ATR ≥ 0.52% |
| 0.070% | ATR ≥ 2.44% | ATR ≥ 0.91% |
| 0.090% | ATR ≥ 3.14% | ATR ≥ 1.17% |
| 0.100% | ATR ≥ 3.48% | ATR ≥ 1.31% |
| 0.130% | ATR ≥ 4.53% | ATR ≥ 1.70% |
| 0.150% | ATR ≥ 5.23% | ATR ≥ 1.96% |

### 3.10 التوقع المسبق — يجب ألا يُكتب التقرير بنبرة متفائلة

```text
ATR على 4H للعملات الكبرى يقع نمطيًا بين 1% و3%
التكلفة المتوقعة في S1 مع السبريد والانزلاق ≈ 0.12% إلى 0.14%
ومنه يلزم ATR ≈ 4.2% إلى 4.9% لتمرير الحد المحافظ
```

```text
الاحتمال الأرجح مسبقًا: الحد المحافظ يفشل، والحد النقطي يمر.
أي أن الحكم المتوقع هو MARGINAL مرة أخرى، لا PASS.
اكتب التقرير على هذا الأساس، وعدّله فقط إن قالت الأرقام غير ذلك.
```

### 3.11 بوابة G2 — الصيغة الحاسمة

```text
احسب cost_R لكل أصل تحت S1
رتّب الأصول تصاعديًا
أبقِ الأصول التي cost_R ≤ 0.0766
```

```text
لا يوجد أصل واحد يحقق ذلك  →  توقف. الحكم FAIL. لا تكمل P3 ولا P4.
يوجد أصل واحد أو أكثر      →  أكمل، على الأصول الباقية فقط
```

وأعد حساب المرشح على الأصول الباقية، وسجّل `N_eff` قبل وبعد.

| CPCV | `N = 6`، `K = 2`، `purge = 18`، `embargo = 18` |

| هل أدمج إلى main | لا. |

## 8. صيغة الحكم النهائي

اكتب واحدًا فقط من هذه، حرفيًا:

```text
PASS       اجتاز المرشح P4 عبر الخيار A، وcost_R تحت 0.0287 على الأصول الباقية،
           وDSR > 0.95، وN_eff ≥ 200

MARGINAL   expectancy موجب نقطيًا وسالب على الحد المحافظ،
           أو نُفذ الخيار B فقط، أو PBO > 0.50، أو DSR < 0.95

FAIL       لا أصل يمرر بوابة G2، أو فشل المرشح في P4

INSUFFICIENT  N_eff < 200 في P4 ولم تتوفر بيانات كافية لأي خيار
```

```text
ممنوع اختراع حكم خامس.
ممنوع كتابة «نتائج واعدة» أو «مؤشرات إيجابية» بلا رقم يسندها.
```

## 9. قاعدة الافتراض الأسوأ

لأي حالة غير مغطاة أعلاه:

```text
1. اختر الافتراض الذي يجعل النتيجة أسوأ لا أفضل
2. سجّله في قسم «قرارات اتُّخذت ذاتيًا»
3. أكمل بلا توقف وبلا سؤال
```

أمثلة تطبيقية:

```text
شككت في السبريد        →  خذ الأعلى
شككت في الانزلاق       →  خذ الأعلى
شككت في احتساب حالة    →  اعتبرها خسارة لا ربحًا
شككت في صلاحية أصل     →  استبعده
شككت بين حكمين         →  خذ الأدنى
```
