# المرحلة P2 — قياس تكلفة التنفيذ

```text
البوابة السابقة: G1
هذه المرحلة لا تقيس أي إشارة. تقيس السوق نفسه.
```

## لماذا هي البوابة الحاسمة

```text
التكلفة ≤ 0.0287R  →  المرشح مربح حتى على الحد المحافظ
التكلفة 0.03–0.076R →  مربح نقطيًا فقط، الحكم MARGINAL يبقى
التكلفة > 0.0766R  →  المرشح ميت، والورقة تنتهي بـFAIL
```

## المطلوب لكل أصل من الأصول التسعة

```text
متوسط السبريد الفعلي بالنقاط الأساسية
رسوم maker ورسوم taker على المنصة المستهدفة
تقدير الانزلاق عند حجم الصفقة المفترض
متوسط ATR بالنسبة المئوية على 4H
```

## التحويل إلى R

```text
حجم المخاطرة R = 1 ATR
cost_R = (السبريد + الرسوم ذهابًا وإيابًا + الانزلاق) / ATR
```

يجب حساب سيناريوهين:

```text
taker_entry_taker_exit   ← الأسوأ
maker_entry_taker_exit   ← الواقعي لإشارة لها 2 شمعة زمن وصول
```

## الترشيح

```text
أي أصل تكلفته > 0.0766R يُستبعد من العينة نهائيًا ويُسجل سبب الاستبعاد
```

ثم يُعاد حساب expectancy للمرشح على الأصول الباقية فقط، مع تسجيل:

```text
عدد الأصول قبل وبعد
N_eff قبل وبعد
win_rate قبل وبعد
```

## معلومة مطلوبة من المالك

```text
اسم المنصة المستهدفة
جدول الرسوم الفعلي للحساب
حجم الصفقة المفترض بالدولار
هل التنفيذ بأوامر maker ممكن أم لا
```

إن لم تُقدَّم، يُستخدم أسوأ افتراض معلن ويُذكر ذلك في التقرير.

```text
PASS       اجتاز المرشح P4 بتكلفة مثبتة، وDSR > 0.95
MARGINAL   موجب نقطيًا وسالب على الحد المحافظ، أو PBO مرتفع
FAIL       فشل عند G2 أو G4
BLOCKED    توقف لنقص معلومة من المالك، مع تحديد المعلومة بالضبط
```

في حالة `FAIL` التوصية الإلزامية:

```text
التوقف نهائيًا عن المؤشرات المشتقة من OHLCV
والانتقال إلى فئة معلومات المشتقات: funding و open interest و taker ratio
```
