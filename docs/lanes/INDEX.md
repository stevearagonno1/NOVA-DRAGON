## كيف تفتح مساراً

1. `python3 tools/new_lane.py "<عنوان قصير>" --type research` → ينشئ `docs/lanes/Lxxxx-*.md` مملوءاً بعقد من `BRAIN.md §7` ويضيف سطراً للوحة.
2. افتح **محادثة جديدة**، الصق فيها قسم `BRIEF ▸ نص الإطلاق` حرفياً.
3. عند النهاية: المسار يملأ `HANDOFF` ويلصق إخراج `tools/audit_lane.py` ثم يرفع (فرع + PR أو نسخة نصية لك).
4. العقل يدقّق ويكتب `VERDICT` + سطر `DECISIONS` إن لزم.

**للعقل:** عمود «حكم العقل» لا يُملأ إلا بعد تدقيق آلي. إن لم يوجد مسار — لا تُشغّل التجربة بنفسك؛ افتح لها محادثة.
