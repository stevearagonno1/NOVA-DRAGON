# TASK-L0075 — اختبار ثلاثة مؤشرات فقط كتأكيد للبنية

## ورقة التسليم لوكيل التنفيذ

هذه هي الخطة المصححة. لا نريد جمع سبعة مؤشرات ولا اختبار عدد كبير من التركيبات ثم اختيار ما يعجبنا. نريد **ثلاثة مؤشرات كلاسيكية فقط** كتأكيد لإشارات البنية.

المؤشرات الثلاثة المقفلة لهذه الجولة هي:


## 4. تعريف المؤشرات الثلاثة

### MACD

```python
long  = (macd > 0) & (macd.shift(1) <= 0)
short = (macd < 0) & (macd.shift(1) >= 0)
```

### EMA50/EMA200

```python
long  = (close > ema50) & (ema50 > ema200)
short = (close < ema50) & (ema50 < ema200)
```

### Stochastic

```python
long  = (stoch_k > stoch_d) & (stoch_k < 25)
short = (stoch_k < stoch_d) & (stoch_k > 75)
```

استخدم الشروط كما هي في `nova_v8/triggers.py`، دون تغيير العتبات.
