## موضع العطب
`history/hyp_lab/common.py` → الدالة `simulate._step`:

```python
if gain >= p["trig"]:                                  # التسليح عند +0.15%
    local = max(p["entry"] * (1 + p["lock"]), peak * (1 - trail))
    eff = max(eff, local)                              # eff = الدخول + 0.60%
if l[j] <= eff:
    _close_position(p, j, eff, "stop")                 # ← البيع عند eff
```

عند بلوغ الربح **+0.15%** يقفز الوقف إلى مستوى القفل **+0.60%**،
**دون اشتراط أن يكون السعر بلغ +0.60% فعلًا**. ثم يُغلق المركز عند ذلك المستوى.
⇒ **الآلة تطبع +0.60% لكل صفقة تتسلّح.**
