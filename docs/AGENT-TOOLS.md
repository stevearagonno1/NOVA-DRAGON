# أدوات العمل مع المساعد — 2026-10-17

## ما أضيف ولماذا
أذن المالك بتطبيق الأدوات لدعم العمل معه على المستودع والمؤشرات. هذه الحزمة تجهز ما يفيد هذا المسار مباشرة وتفصل التجهيز عن التشغيل الفعلي. لا تغيير في المحرك أو البوت أو البيانات أو شروط التجارب.

| الأداة | الحالة في هذه الحزمة | طريقة الاستفادة |
|---|---|---|
| Agent Skills | نسختان أصليتان مثبتتان بمرجع Git داخل .agents/skills/ مع الرخصة ومرجعي المراجعة | مراجعة الكود واختبار السلوك عند تعديل المؤشرات |
| Context7 | مثال إعداد HTTP جاهز للمضيف المتوافق؛ الاتصال غير مختبر هنا | طلب توثيق المكتبة بإصدارها عند الحاجة |
| Graphify | مسار استخدام موثق؛ غير مثبت وغير مشغّل | تحليل نطاق صغير من الكود عند تعقّد العلاقات |
| Strix | مؤجل؛ غير مثبت وغير مشغّل | فحص أمني معزول عند الحاجة |
| 21st | مؤجل؛ غير متصل | بناء واجهة تقارير عند طلبها |
| Ruflo | مؤجل؛ غير مثبت وغير مشغّل | تنسيق وكلاء فقط عند وجود حاجة وإذن صريح |

**وجود أداة في هذا الجدول لا يعني أنها متاحة للمساعد داخل ChatGPT.** إضافة GitHub تتيح قراءة وتعديل الملفات ضمن صلاحياتها، ولا تجعل خوادم MCP المكتوبة في المستودع أدوات قابلة للاستدعاء داخل المحادثة. كذلك لا يضمن هذا الفرع الاكتشاف التلقائي للمهارات في كل مضيف.

## كيف يعمل المساعد معي
1. يقرأ AGENTS.md والدستور وحالة المشروع، ثم قائمة docs/INDICATOR-REVIEW.md.
2. يقرأ المهارة المناسبة صراحةً عبر GitHub إذا لم يدعم المضيف اكتشاف .agents/skills/.
3. يحدد التعديل والفحص اللازم؛ يراجع الحساب والتوقيت والأدلة، ولا يغيّر المحرك المقفل دون إذن محدد.
4. يرجع إلى Context7 عند توفره لتوثيق المكتبة وإصدارها؛ وإلا يستخدم توثيقها الرسمي المتاح ويذكر حد الوصول. لا يرسل بيانات خاصة أو أسرارًا في الاستعلام.
5. ينشر العمل المأذون وأدلته على فرع مستقل. الدمج للمالك وفق الدستور.

المهارتان مستوردتان دون تعديل من addyosmani/agent-skills؛ المصدر والبصمات في .agents/UPSTREAM.json والرخصة في .agents/LICENSE. مرجعا الأمن والأداء موجودان في .agents/references/ كما تتوقع المسارات النسبية. الإشارات داخل النص لمهارات أخرى ليست مهارات مثبتة؛ لا تُستدعى إلا بعد تجهيزها بصورة منفصلة. تعليمات النشر والدمج والتفويض العامة لا تتجاوز الدستور أو إذن المالك.

## Context7
المثال tools/agent_support/context7.mcp.example.json يستهدف عميلًا يفهم mcpServers وخادم HTTP. ليس ملف إعداد عام لكل العملاء، ولا يُنسخ عشوائيًا إلى إعداد Codex أو ChatGPT. يتطلب التسجيل في المضيف المتوافق واختبار اتصال من داخل ذلك المضيف قبل وصفه بأنه فعال.
إذا طُلِب مفتاح وصول، يوضع في مخزن أسرار المضيف أو متغيراته، ولا يُحفظ في المستودع. لا مفاتيح في المثال.
يحدد المساعد الإصدار المستخدم فعلًا؛ لا يحدّث اعتماديات التجربة لمجرد وصول توثيق أحدث.

## Graphify
المصدر الرسمي: https://github.com/Graphify-Labs/graphify .
اسم حزمة Python الرسمي graphifyy، والأمر graphify. المسار الموثق من المصدر هو تثبيت CLI ثم تسجيل المهارة للمضيف، ويمكن التسجيل داخل المشروع.
لم تُنفّذ هذه الخطوات هنا. قبل التجهيز الفعلي: تحقق من الإصدار ومتطلبات البيئة والحجم وطريقة استبعاد الملفات، ثم شغّل تحليل الكود فقط على نطاق مأذون صغير.
ابدأ بملفات مؤشر وأداة بحث محددة، لا المستودع كله. استبعد data/ وcrypto_archive/ وold/ والأرشيفات الثنائية والمفاتيح. الوثائق والوسائط قد تستخدم نموذجًا خارجيًا؛ لا تُفعّل تحليلها ضمنيًا.
أي علاقة مستنتجة في الخريطة تحتاج الرجوع إلى المصدر؛ الخريطة لا تثبت صحة الحساب أو غياب النظر للمستقبل.

## الأدوات المؤجلة
- Strix يحتاج بيئة اختبار معزولة وموارد Docker/نموذج بحسب طريقة التشغيل. نطاقه أمان التطبيق فقط؛ لا منصة التداول ولا حسابات أو أموال حقيقية. لا فحص آلي عند كل تغيير في المؤشرات.
- 21st يخدم واجهة عرض النتائج عند طلبها. لا حاجة لإضافة واجهة أو اعتماديات JavaScript إلى البحث الحالي.
- Ruflo لا يحل محل ذاكرة المستودع أو المراجعة أو قواعد التفويض. لا تفعيل تلقائي للوكلاء أو التداول أو التعلم الذاتي أو الرفع.
- استئناف هذه الأدوات يكون بمهمة محددة وتجهيز متحقق، لا بمجرد تغيير حالتها في هذا الجدول.

## التحقق وحدوده
أداة tools/agent_support/check_setup.py تفحص بصمات الملفات المستوردة، بيانات المهارتين، المرجعين، ومثال Context7 دون شبكة أو استيراد كود التداول.
نجاحها يثبت سلامة حزمة الملفات فقط؛ لا يثبت تحميل المهارات في المضيف، ولا اتصال MCP، ولا تشغيل Graphify/Strix/21st/Ruflo، ولا تحسن الربحية.
الفحص الفعلي على مؤشر قائم لم ينفذ ضمن مهمة الدمج هذه. لا قياس سوق جديد ولا تغيير حكم سابق.
