# ٩) الفترتان والقواعد المنهجية — لا تُمَس

```
فترة الاختيار : 2021-09-01 → 2023-12-31
فترة الحكم    : 2024-01-01 → 2026-08-31
التسخين       : من 2021-06-01
```
- **اختر من الاختيار وحده · ثبّت في ملف · اقِس على الحكم مرة واحدة.**
- **ممنوع** تعديل إعداد بعد رؤية نتيجة الحكم.
- **سقف محاولات معلن** لكل جولة، والضوابط العشوائية **تُحسب منه**.
- **الضابط العشوائي إلزامي** — 5 بذور · الفوز = تجاوز **أسعد** بذرة.
- **الحتمية:** إعادة تشغيل + مقارنة sha256.
- **ما لم يُقَس يُكتب «لم يُقَس».**

## مصنّف المناخ — حرفيًّا
```python
dly   = to_bars(df1m, 1440)
c     = dly["close"]
e50   = c.ewm(span=50,  adjust=False).mean()
e200  = c.ewm(span=200, adjust=False).mean()
slope = e50.diff(10)
lab = pd.Series("عرضي", index=dly.index)
lab[(e50 > e200) & (slope > 0)] = "صاعد"
lab[(e50 < e200) & (slope < 0)] = "هابط"
lab = lab.shift(1)          # ⚠️ إلزامي — بدونه تقرأ المستقبل
```
⚠️ **لا تستعمل `nova_v8/regime.py`** — يقرأ إطار 15 دقيقة فيصف تقلّب اللحظة
لا مناخ السوق (يعطي «عرضي 86%»).
