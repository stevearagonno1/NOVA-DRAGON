# 📼 الشريط — دفتر نبضات الجلسات (الدستور، القسم ٢٦)

> «الشريط لا يكذب ولا يرجع» — كل نبضة مشروع تُطبع هنا لحظة حدوثها، ولا تُمحى أبدًا.

## القواعد الملزمة

- **كل جلسة عمل = مجلد** باسم: `YYYY-MM-DD-اسم-الجلسة`
- **كل حدث مغيِّر = ملف مرقم جديد:** `NNN-عنوان-قصير.md` (٠٠١، ٠٠٢، ٠٠٣…) يشرح أربعة أسطر بلغة التداول:
  1. ماذا تقرر
  2. ماذا نُفِّذ
  3. ما الذي أُنتج
  4. ما التالي
- **ما يستحق تكة:** نتيجة تجربة · قرار · أمر جهاز للمستخدم · تعديل مستودع · تعليمات من القائد · حدث طارئ. المجاملات والردود الفارغة لا تكة لها.
- **الرفع الفوري:** كل تكة تُلتزم وتُرفع لفرع الجلسة فور كتابتها، قبل أي رسالة تالية — فموت الجلسة لا يكلف أكثر من دقائق.
- **الشريط لا يرجع:** لا تُعدَّل تكة ولا تُحذف أبدًا؛ التصحيح تكة جديدة تشير إلى سابقتها.
- **المراجعة واجبة:** كل جلسة جديدة تقرأ هذا البيت قبل أول حركة وتستأنف من آخر نبضة — لا من الصفر.
- **الدمج:** تكات الجلسة تركب حزمة عملها مرة واحدة بيد القائد. `LOG.md` يبقى ملخص التاج.
