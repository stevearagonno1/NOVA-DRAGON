# 2026-10-02 — تخفيف سياق التشاور

- طلب المالك تنفيذ تخفيف الجولات بعد توقف مراجعة الملفات عند المهلة العامة؛ لم يظهر رفض للمفاتيح.
- القراءة المستقلة تحتفظ بالمصادر الكاملة، ثم تستخدم الجولات والتوليف المقاطع الأصلية المستشهد بها مع رقم الإيداع والآراء والاعتراضات.
- المراجع غير المتاحة أو تجاوز ميزانية الأدلة تمنع اعتماد الإجماع؛ لا اقتطاع صامت ولا تلخيص مولّد بديل للمصدر.
- اجتاز التعديل 74 اختبارًا محليًا؛ زمن الخادم يحتاج اختبارًا جديدًا بعد النشر. لا تعديل لـmain أو استراتيجية التداول.
