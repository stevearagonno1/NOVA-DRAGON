## ٥) تصميم هيكل البوت متعدد الاستراتيجيات

الفكرة: **راوتر حالات سوق + أجنحة استراتيجيات مستقلة + طبقة مخاطر حاكمة** — مبني على `nova_v8/regime.py` و`risk.py` و`strategy_registry.py` القائمة، لا من الصفر.

```
البيانات (1m → تجميع) 
      ↓
[محرك الحالة]  regime.py — 4 حالات من فريم أعلى (15m) مع تأخير وقائي + هيستيريسيس:
   اتجاهاع (BULL) · اتجاه هابط (BEAR) · عرضي (CHOP) · صدمة (SHOCK)
      ↓
[الراوتر]  يختار الجناح حسب الحالة والارتباط
      ↓
┌────────────┬────────────┬────────────┬────────────┐
│ BULL       │ BEAR       │ CHOP       │ SHOCK      │
│ القواطع    │ لا شراء —  │ الشبكة     │ توقف شامل  │
│ F-213 +    │ الحياد     │ الحاصدة +  │ + خفض أحجام│
│ F-192/F-165│ هو المركز  │ دورة التراكم│            │
└────────────┴────────────┴────────────┴────────────┘
      ↓
[طبقة الخروج الموحّدة]  F-197 مطاردة ثنائية + وقف 2×ATR
      ↓
[طبقة المخاطر]  risk.py
   • حجم الصفقة: 2% من محفظة التجربة (20$) — الحي: قاعدة 5% بسقف 1000$ (D-0043)
   • وقف كل صفقة: 2×ATR14
   • الحد اليومي: −3% من إجمالي المحفظة ⇒ إيقاف اليوم
   • قاطع الطوارئ: −25% من القمة التاريخية ⇒ توقف كلي + مراجعة
   • صدمة سعرية: خفض تلقائي للأحجام
      ↓
[التنفيذ]  spot فقط · لا رافعة · لا بيع مكشوف · لا سحب تلقائي (الحواجز الحديدية §8)
      ↓
[السجل والتدقيق]  state + record_trade + كاناري
```

**قواعد الراوتر المقترحة (توسعة لما هو مبني في قسم ٧ من سجل الأحكام):**
1. **صاعد:** القواطع + فرضيات الدخول (F-192/F-165/F-001) بحجم كامل.
2. **هابط:** لا شراء جديد — الحياد هو المركز (الدرس من نافذة الاختبار).
3. **عرضي:** الشبكة الحاصدة + دورة التراكم (إشارات نادرة).
4. **صدمة:** توقف شامل فوري + لا استئناف إلا بمراجعة.
5. **تعديل الارتباط:** GRAM–TON توأم (0.959) يُعدّان مركزاً واحداً — لا مضاعفة تعرّض.
6. **الترابط المقيس:** متوسط 0.295 بين أجنحة المحفظة ⇒ تنويع حقيقي لا تكرار.

**شرط الاعتماد قبل أي مال حي (لا يُتجاوز):** المسبار الورقي L0011 مرة واحدة على المحفظة النهائية الموحدة، ثم شبكة تجريبية أسبوعين، ثم 200$ حقيقية. **لا مفاتيح في المستودع أبداً؛ لا تداول حقيقي قبل ذلك.**
